HashiCorp Vault KV v2 uses no extra Python dependency. Configure its address,
mount and auth_env; the Vault token itself stays in the named environment
variable and is not persisted in provider config.

Automatic managed_random rotation is disabled unless a rotation policy explicitly
enables it. It is intended only for system-owned secret material whose backing
provider can safely accept a new random value. Third-party API credentials should
remain monitor_only or use a registered external_handler.
