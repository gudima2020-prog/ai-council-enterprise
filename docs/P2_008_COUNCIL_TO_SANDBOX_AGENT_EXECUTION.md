# P2-008 — Council-to-Sandbox Agent Execution

P2-008 connects Council decisions to the P2-007 Git-isolated Code Sandbox through a capability-limited coding agent.

## Safety model

The coding model receives only:

- the explicit task and, optionally, the final answer of a saved Council run;
- UTF-8 text from explicitly selected context files;
- an exact allowlist of writable relative paths.

It does **not** receive shell access, arbitrary filesystem access, network tools, secrets, database sessions, or credentials. The model returns a strict JSON edit plan containing full-file `write`, exact-once localized `replace`, or `delete` operations. `replace` is preferred for ordinary edits to reduce output tokens. The server validates the plan before touching the worktree.

## Execution flow

```text
Task / saved Council run
        ↓
Explicit context + writable allowlist
        ↓
AI Gateway coding model
        ↓
Strict JSON edit plan
        ↓
Path/schema/size/TOCTOU validation
        ↓
Writes ONLY inside detached worktree
        ↓
P2-007 Inspect + risk classification
        ↓
Automatic safe Verification (diff_check / python_compile only)
        ↓
Human review; optional host pytest/build as a separate manual step
        ↓
Human approval
        ↓
Separate safe Apply action
```

The agent never calls `apply()` automatically.

## Path guards

- absolute paths and `..` traversal are rejected;
- `.git` is inaccessible;
- `.gitattributes` and `.lfsconfig` are agent-blocked so a generated attributes mapping cannot activate trusted-global Git filters before human approval;
- P2-007 blocked paths such as real `.env`, private keys, runtime SQLite, `.venv`, and `node_modules` cannot be read or written by the agent;
- existing symlink components are rejected;
- writable files are snapshotted before the LLM call and rechecked before edits to prevent concurrent-change TOCTOU;
- operation count and per-file/total generated bytes are bounded.

## Council handoff

`POST /api/code-sandbox/sessions/{session_id}/agent-runs` accepts an optional `council_run_id`. Only a successful/partial saved run from the same Workspace with a non-empty final answer can be used.

The full generated prompt and source context are not stored in the audit table. The run stores a task SHA-256, a short preview, provider/model, token usage, provider-reported cost when available, and operation metadata.

## API

## Isolation boundary

P2-008 is an application-level capability boundary, **not** an OS container/VM. Agent auto-verification never runs host `pytest` or frontend builds; those remain separate manual P2-007 actions and are additionally governed by `AI_STUDIO_CODE_SANDBOX_ALLOW_TEST_EXECUTION`. A future runtime stage should add process, network, CPU, memory and filesystem isolation for untrusted code execution.
