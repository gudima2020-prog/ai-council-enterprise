# React frontend v0.9.0

Стек: React 19, TypeScript и Vite 8.

## Запуск

Установка выполняется корневым `install.bat`. Для ручного запуска:

```cmd
run_api.bat
```

```cmd
run_frontend.bat
```

Откройте <http://127.0.0.1:5173>. API docs доступны на
<http://127.0.0.1:8000/docs>.

## Реализованные экраны

- Chat: режим, вопрос, ответ AI Gateway;
- AI Council: выбор 2–6 моделей, назначение ролей, запуск;
- отчёт: итог, confidence, консенсус, разногласия, рекомендации;
- раскрываемые независимые ответы, понятные ошибки и free fallback route;
- история Council с поиском, фильтрами status/mode/date и пагинацией;
- карточка сохранённого отчёта, повтор с тем же составом и удаление;
- настройки срока хранения, автоматической очистки, ответов участников и
  token usage;
- live progress каждого участника через EventSource;
- поток итогового синтеза, автоматическое переподключение, отмена и тайм-аут;
- live replay и повтор только неуспешных участников;
- отдельное отображение отменённых запусков в истории;
- адаптивная компоновка для узкого окна.

Каталог загружается из `GET /api/models?enabled_only=true`. Бесплатные модели
выбираются первыми; тарифицируемые помечаются до запуска. Устаревшие
starter-модели с `catalog_hidden` не показываются в новом составе Совета, но
остаются доступны действующим Workspace policy.

Если конкретная бесплатная модель временно недоступна, отчёт явно показывает
переход `requested_model → openrouter/free`. Код ошибки и объяснение доступны
в карточке участника; платные модели автоматически не подставляются.

## Production build

```cmd
cd frontend
npm ci
npm run build
```

Каталог `frontend/dist/` является build artifact и не входит в исходный архив.

Replay всегда требует подтверждения. Если сохранённый состав содержит модель,
которая сейчас помечена как тарифицируемая, интерфейс показывает усиленное
предупреждение. Удаление записи также требует отдельного подтверждения.

Настройки конфиденциальности применяются к новым запускам. Отключение хранения
ответов участников не удаляет итоговый синтез; для уже сохранённых записей
используйте явное удаление или очистку по сроку.
