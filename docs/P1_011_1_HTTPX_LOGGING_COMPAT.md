# P1-011.1 — httpx logging compatibility fix

## Причина

В API smoke tests сочетание Python 3.13, httpx и TestClient формирует
лог-запись:

```text
HTTP Request: %s %s "%s %d %s"
```

При этом код ответа передаётся строкой (`"200"`), а `%d` требует число.
Из-за этого pytest и JSON formatter падали уже после успешного ответа API.

## Исправление

Добавлен pytest filter в:

```text
tests/conftest.py
```

Он:

- применяется только к logger `httpx`;
- применяется только к известному шаблону HTTP Request;
- преобразует строковый код ответа `"200"` в число `200`;
- не подавляет логи;
- не изменяет остальные записи.

Добавлены отдельные тесты совместимости.

## Проверка

```powershell
.\run_tests.bat
```

Ожидаемый результат:

```text
41 passed
TEST RESULT: PASSED
```

Фактическое число тестов может быть больше, если в проекте уже добавлены
другие тестовые модули.
