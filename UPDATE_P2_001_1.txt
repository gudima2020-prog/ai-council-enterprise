AI STUDIO ENTERPRISE v0.6.0 / P2-001.1
=======================================

WINDOWS PYTHON 3.13 TEST HOTFIX

Причина:
старый regression-тест сохранял только id() очереди после завершения lifespan.
Python 3.13 мог освободить объект и законно выдать тот же адрес памяти новому
экземпляру. Runtime корректно создавал новую очередь, но тест возвращал ложную
ошибку: assert 2 == 3.

Порядок обновления:

1. Остановите backend и frontend.
2. Распакуйте cumulative-архив поверх:
   C:\Projects\ai-council-enterprise
3. Запустите:

   .\run_tests.bat

Ожидаемый результат:

   273 passed
   TEST RESULT: PASSED

Миграцию базы повторять необязательно: Alembic head остаётся
20260716_0043. Runtime-код, .env и data не изменяются.
