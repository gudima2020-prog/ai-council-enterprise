AI Studio Enterprise v0.2 GUI patch

Как установить:

1. Распакуйте архив поверх папки:
   C:\Projects\ai-council-enterprise

2. Подтвердите замену файлов.

3. В папке проекта выполните:
   install.bat

4. Запуск графической версии:
   run_gui.bat

Консольная версия остается:
   run.bat

Если установка PySide6 идет долго — это нормально.
